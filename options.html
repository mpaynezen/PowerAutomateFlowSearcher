Azure AD Setup Checklist

Your app registration needs the Power Automate Service API permission Flows.Read.All (delegated). An admin may need to grant consent for the org.
  1. Go to portal.azure.com → Azure Active Directory → App registrations
  2. Open your app registration (or create a new one)
  3. Go to Authentication → Add a platform → Single-page application (SPA)
  4. Paste the Redirect URI above and save
    Important: must be SPA, not "Mobile and desktop" — PKCE requires it
  5. Go to API permissions → Add a permission → APIs my organization uses → search Power Automate
  6. Select Flows.Read.All (delegated) and add it
  7. If required by your org, click Grant admin consent
  8. Copy the Application ID and Directory (tenant) ID from the Overview page and paste them above
